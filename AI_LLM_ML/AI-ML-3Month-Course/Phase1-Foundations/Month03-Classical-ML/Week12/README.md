# Week 12 — Unsupervised Learning + Capstone 1

No labels, no loss oracle — unsupervised methods are the closest ML gets to "what
structure is in this detector data?"; then Capstone 1 ships everything Phase 1 built.

## Objectives

- Implement k-means and state what objective it descends (and where it gets stuck).
- Derive EM for Gaussian mixtures — responsibilities, then the M-step updates.
- Use PCA and UMAP for exploration, knowing what each preserves and distorts.
- Ship Capstone 1: a tested, calibrated, honestly-validated particle-ID classifier.

## Core material (~3 hrs)

- Bishop, *PRML* Chapter 9 (mixture models and EM) — the core read; §9.1 k-means,
  §9.2 GMMs, and the EM view. Also skim §12.1 to reconnect PCA.
- StatQuest: k-means and GMM videos for the fast pass; UMAP video for intuition.
- UMAP documentation: "How UMAP works" and the "Understanding UMAP" interactive
  article (Coenen & Pearce) — focus on what distances/densities you may NOT read off
  the embedding.
- MAGIC Gamma Telescope dataset page (UCI ML Repository): read the feature
  descriptions — they are Hillas parameters, i.e., shower-shape variables you already
  have intuition for.

## Derivations (paper first)

- k-means as coordinate descent on the within-cluster sum of squares; show each step
  cannot increase the objective.
- EM for a GMM: write the complete-data log-likelihood, derive responsibilities
  (E-step), then the μₖ, Σₖ, πₖ updates (M-step). Note where k-means reappears as the
  ε → 0 limit.
- One line each: what PCA preserves (global variance directions) vs what UMAP tries to
  preserve (local neighborhoods).

## Exercises (built when the week starts)

1. **k-means from scratch.** Lloyd's algorithm on 2D blobs; plot assignments and
   centroid tracks; run from 20 seeds and keep the best objective.
   Accept when: objective is monotone non-increasing every run and best-seed centroids match sklearn `KMeans` to 1e-4.
2. **EM from scratch.** GMM on overlapping blobs using your derived updates; plot
   log-likelihood per iteration and the fitted ellipses.
   Accept when: log-likelihood is monotone and parameters match sklearn `GaussianMixture` (same init) to 1e-3.
3. **PCA vs UMAP on MAGIC.** Embed the 10 Hillas features both ways, colored by class;
   note in ≤3 lines what each embedding shows and what it cannot show.
   Accept when: both embeddings render with a shared legend and the caption states one distortion of each method.

**Capstone 1 — tabular particle-ID classifier** (MAGIC gamma/hadron, UCI):

4. **Pipeline.** sklearn `Pipeline` from raw CSV to prediction: split, preprocess,
   model (logistic baseline + tuned XGBoost from Week 11), all seeded.
   Accept when: fresh clone + `uv sync` + one command reproduces the result table.
5. **Nested CV.** Outer CV for performance, inner CV for hyperparameters; report
   AUC with fold spread for both models.
   Accept when: the table shows outer-fold mean ± spread and no hyperparameter was chosen using outer-fold test data.
6. **Calibration + working points.** Reliability curve for the final model; thresholds
   at 90% gamma efficiency and at max S/√(S+B); confusion matrices for each.
   Accept when: calibration plot is in the repo and both working points are reproduced by `pytest` to 1% on the held-out set.
7. **Writeup.** ~2 pages: problem, data, method, results table, calibration figure,
   what failed first, and limitations.
   Accept when: `writeup.md` exists, includes the failure section, and every number in it is generated by the pipeline.
