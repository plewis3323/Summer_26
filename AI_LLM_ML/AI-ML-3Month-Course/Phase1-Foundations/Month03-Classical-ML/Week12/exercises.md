## E1 — k-means from scratch

Implement Lloyd's algorithm on the provided 2D blobs: nearest-centroid
assignment, mean update, empty-cluster re-seed. Plot assignments and centroid
tracks (the path each $\mu_k$ took). Run from 20 seeds, keep the smallest
WCSS $J$, and overlay $J$ vs iteration for that run (it must never tick up).
Hint: lesson §2.1; one assignment step is
`((X[:, None, :] - mu)**2).sum(axis=2).argmin(axis=1)`. Compare the
best-seed centroids to `sklearn.cluster.KMeans(n_clusters=K, n_init=20,
random_state=0)` after matching labels (Hungarian / greedy by nearest
center — permutation of $k$ is free).
Accept when: $J$ is monotone non-increasing every run and the best-seed
centroids match sklearn `KMeans` to 1e-4.

## E2 — EM from scratch

Fit a $K$-Gaussian mixture on the provided overlapping blobs with your
derived E-step (responsibilities) and M-step ($\pi_k,\mu_k,\Sigma_k$).
Plot log-likelihood per iteration and the fitted 2-$\sigma$ ellipses over
the data. Initialize from the same means / covariances / weights the
notebook hands to sklearn.
Hint: lesson §3.3–3.4; $\gamma_{ik}$ is Bayes with prior $\pi_k$ and
likelihood $\mathcal{N}(x_i\mid\mu_k,\Sigma_k)$. A 2-$\sigma$ ellipse is
the level set $(x-\mu)^\top\Sigma^{-1}(x-\mu)=4$; `np.linalg.eigh(Sigma)`
gives the axes. Add $10^{-6}I$ to each $\Sigma_k$ if a component collapses.
Accept when: log-likelihood is monotone and parameters match sklearn
`GaussianMixture` (same init) to 1e-3.

## E3 — PCA vs UMAP on MAGIC

Embed the 10 Hillas features of the cached MAGIC table both ways, colored
by class (`g`/`h`), sharing one legend. PCA: your Week 07 code or
`sklearn.decomposition.PCA(n_components=2)` on a `StandardScaler` fit
**on the training rows only**. UMAP: `umap.UMAP(random_state=0)` on the
same scaled training rows. Write a caption of at most 3 lines stating
what each embedding shows and one distortion of each method.
Hint: lesson §4; do not read inter-cluster distances or densities off
UMAP. Fit the embedders on train, transform train (and optionally a
held-out sample) — fitting UMAP on the test set is a look-ahead.
Accept when: both embeddings render with a shared legend and the caption
states one distortion of each method.
