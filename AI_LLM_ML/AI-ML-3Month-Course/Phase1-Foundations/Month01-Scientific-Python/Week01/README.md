# Week 01 — Your first programs

You have never written code; by Sunday you will have written, run, broken, and
fixed several programs. This week is the terminal, Python itself, and the calm
reading of error messages — the foundation every later week stands on.

## Objectives

- Open a terminal and navigate with `pwd`, `ls`, `cd`, `mkdir`, and Tab completion.
- Install Python via `uv` and start it three ways: interpreter, script, notebook.
- Use variables, integers, floats, and strings; convert between them deliberately.
- Write a script that takes `input`, computes, and `print`s formatted results.
- Read a traceback bottom-up and name the five common error types on sight.

## Core material (~3 hrs)

- `lesson.md` (this folder) — the primary text; work through it at the keyboard,
  typing everything.
- `02-Setup-Guide.md` (course root) — Day 0 and the Week 01 environment block;
  do the install steps as the lesson reaches them.
- Severance, *Python for Everybody* (free online), chapters 1–2 — a gentler
  second pass with videos.
- The official Python Tutorial, sections 1–3 — the same ground in the
  language's own voice; skim.

## Exercises

See `exercises.md` (notebook generated when the week starts, per
`NOTEBOOK_RULES.md`). Seven exercises: terminal navigation, calculator work,
variables, string handling, two small input-driven scripts, and a deliberate
error-breaking-and-fixing set — ending with a script that ties the whole week
together.

## Deliverable

`notebooks/Week01_Exercises.ipynb` with all checks PASS, plus `half.py` and
`greeter.py` running cleanly from the terminal in your `week01` folder.
