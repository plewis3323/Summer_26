# Month 06 — Geometric DL, Generative Models, and Software for Services

The arc: graphs, generators, then the software that lets other programs call
what you built. Week 21 drops the fixed-grid assumption — message-passing GNNs
on point clouds or graphs (ParticleNet, citation graphs, and molecules are the
same idea). Week 22 builds VAEs with the ELBO derived line by line. Week 23 is
**software engineering II**: SQL, HTTP/JSON, FastAPI, Docker — a small service
over a table you own, so Week 44 is a spiral. (Normalizing flows, the old Week
23, are `optional-flows.md` for generative-sim tracks.) Week 24 is Capstone 2:
a GNN classifier or a VAE generator, science data or a public set, same eval
discipline.

**Month-end deliverable:** Capstone 2 — tested repo + writeup; the Phase 2 gate
also requires re-doing the backprop and ELBO derivations cold, and Week-23
service tests green.

**Sign-off:** tag `month-06-complete`, write `retro.md` (~250 words), open one
issue for the biggest thing you still don't understand.
