*Data Transformations: 

Data transformations are steps used to change or adjust data before using it in a machine learning model. These steps can include:

Changing values to a common scale (scaling or standardizing)
Grouping values into bins (binning)
Turning text or categories into numbers (encoding)
Fixing missing or incorrect values
These changes help models understand the data better and make more accurate predictions.

* This process is called numerical transformation, 
when we take our numerical data and change it into another numerical value. 
This is meant to change the scale of our values or even adjust the skewness of our data.

* Data centering involves subtracting the mean of a data set from each data point so that the new mean is 0. 
This process helps us understand how far above or below each of our data points is from the mean.

ex.) Centering your data example: 
import pandas as pd
import numpy as np
import matplotlib.pyplot as plt 
import codecademylib3_seaborn 

#Pandas object
coffee = pd.read_csv('starbucks_customers.csv')

#define feature of speciifc column
ages = coffee['age']

#minimum age feature 
min_age = np.min(ages)
print(min_age)

#maximum age feature 
max_age = np.max(ages)
print(max_age)

#difference in ages 
diff = max_age - min_age 
print(diff) 

#mean of data 
mean_age = np.mean(ages)
print(mean_age)


#centering the data 
centered_ages = ages - mean_age 
print(centered_ages)

#display results as histogram 
plt.hist(centered_ages)
plt.show()
