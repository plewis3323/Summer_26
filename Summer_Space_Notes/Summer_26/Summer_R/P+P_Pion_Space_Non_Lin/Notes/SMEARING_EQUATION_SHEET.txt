1.  THE RESOLUTION FUNCTION  (3-term calorimeter form)
--------------------------------------------------------------------------------

        sigma(E)             p0^2     p1^2
        --------  =  sqrt(  ------  + ------  +  p2^2  )          (E in GeV)
           E                  E        E^2

    TERMS:
        p0  =  stochastic / sampling term   ("a/sqrt(E)")
        p1  =  noise term                   ("b/E")
        p2  =  constant term                ("c")

    Equivalent quadrature notation used in the calibration talks:

        sigma_E / E  =  p0/sqrt(E)  (+)  p1/E  (+)  p2

        where "(+)" denotes addition in QUADRATURE.


2.  THE EXTRA SMEARING APPLIED TO MC
--------------------------------------------------------------------------------

    A Gaussian of width  sigma_extra(E) * E  is added to the simulated
    cluster energy, with the width set by the quadrature DIFFERENCE between
    the data and MC resolutions:

        sigma_extra(E)  =  sqrt(  max( 0,  sigma_data^2(E) - sigma_MC^2(E) )  )

        smearing ~  N( 0,  sigma_extra(E) * E )
