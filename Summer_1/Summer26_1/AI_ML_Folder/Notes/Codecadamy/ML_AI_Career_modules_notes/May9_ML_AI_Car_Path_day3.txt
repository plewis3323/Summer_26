* Log transforms:  


-  Data transformations are steps that change or adjust data to make it more useful for analysis or machine learning. 
   Examples include scaling values, encoding categories, binning continuous data, and handling missing values. 
   These changes help models understand the data better and improve performance.
   

- Log transformation helps with right-skewed data and large outliers.
- It makes data closer to a normal distribution.
- It reduces the range of values, making features easier for models to handle.
- Log transformation is not suitable for negative values or left-skewed data.
- After log transformation, relationships in models may become multiplicative instead of additive.

#* Encoding Categorical Variables 

- Categorical data can be nominal (no order) or ordinal (ordered).
- Many machine learning models require categorical data to be converted to numbers.
- Ordinal encoding assigns numbers based on order or hierarchy.
- Label encoding assigns a unique number to each category, but can create false order.
- One-hot encoding creates a new column for each category, using 1s and 0s.
- Binary encoding reduces the number of columns by using binary numbers.
- Hashing encoding maps categories to a fixed number of columns, but can cause collisions.
- Target encoding replaces categories with the mean of the target variable for each category.
- Date-time features can be split into parts like year, month, or day for analysis.

ex.) (condition mapping) (scikit example) 

# using scikit-learn
from sklearn.preprocessing import OrdinalEncoder

# create encoder and set category order
encoder = OrdinalEncoder(categories=[['Excellent', 'New', 'Like New', 'Good', 'Fair']])

# reshape our feature
condition_reshaped = cars['condition'].values.reshape(-1,1)

# create new variable with assigned numbers
cars['condition_rating'] = encoder.fit_transform(condition_reshaped)

*One-hot encoding 

- One-hot encoding is when we create a dummy variable for each value of our categorical feature, 
and a dummy variable is defined as a numeric variable with two values: 1 and 0. 
We will continue to talk about our color feature from our used car dataset.


ex.) (one-hot encoding) 

# use pandas .get_dummies method to create one new column for each color
ohe = pd.get_dummies(cars['color'])

# join the new columns back onto our cars dataframe
cars = cars.join(ohe)

* Hashing

- Another option we have available to us is an encoding technique called hashing. 
This process is similar to one-hot encoding where it will create new binary columns, but within the parameters, 
you can decide how many features to output. A huge advantage is reduced dimensionality, but a large disadvantage 
is that some categories will be mapped to the same values. That is called collision.

ex.) 

from category_encoders import HashingEncoder

# instantiate our encoder
encoder = HashingEncoder(cols='color', n_components=5)

# do a fit transform on our color column and set to a new variable
hash_results = encoder.fit_transform(cars['color'])
