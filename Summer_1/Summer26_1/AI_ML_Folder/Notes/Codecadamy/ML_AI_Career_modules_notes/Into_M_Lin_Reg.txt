 - Introduction to Multiple Linear Regression:
 
 
Multiple Linear Regression uses two or more independent variables 
to predict the values of the dependent variable. It is based on the following equation that we’ll explore later on:

  y = b + m1x1 + m2x2 + m3x3 + .... + mNxN

- Multiple Linear Regression: Scikit-Learn:

* Multiple linear regression models the relationship between one target and several features.
Use LinearRegression() from sklearn.linear_model for multiple features.
Fit the model with .fit(x_train, y_train).
Predict values with .predict(x_test).
The model finds coefficients for each feature and an intercept.
Steps are similar to simple linear regression, just with more features.


ex.)

- Multiple Linear Regression Equation: 


* Multiple linear regression predicts a target using several features.
The equation is:
y = b + m₁x₁ + m₂x₂ + … + mₙxₙ
b is the intercept; m₁, m₂, …, mₙ are coefficients for each feature.
Coefficients show how much each feature affects the prediction.
Use .coef_ for coefficients and .intercept_ for the intercept in scikit-learn.


ex.)

- Evaluating the Model's Accuracy:

Residual analysis checks the difference between actual and predicted values.
Residual (e) is calculated as: e = y - ŷ
Use .score() method to get R² (coefficient of determination).
R² shows the percentage of variation in y explained by the model.
R² ranges from negative values to 1.0; higher is better.
R² of 0.70 or above is usually considered good.


ex.)

import codecademylib3_seaborn
import matplotlib.pyplot as plt
import pandas as pd

from sklearn.model_selection import train_test_split
from sklearn.linear_model import LinearRegression
from sklearn.metrics import mean_squared_error

streeteasy = pd.read_csv("https://raw.githubusercontent.com/sonnynomnom/Codecademy-Machine-Learning-Fundamentals/master/StreetEasy/manhattan.csv")

df = pd.DataFrame(streeteasy)

x = df[['bedrooms', 'bathrooms', 'size_sqft', 'min_to_subway', 'floor', 'building_age_yrs', 'no_fee', 'has_roofdeck', 'has_washer_dryer', 'has_doorman', 'has_patio', 'has_gym']]

y = df[['rent']]

x_train, x_test, y_train, y_test = train_test_split(x, y, train_size = 0.8, test_size = 0.2, random_state=6)

lm = LinearRegression()

model = lm.fit(x_train, y_train)

y_predict= lm.predict(x_test)

print("Train score:")
print(lm.score(x_train, y_train))

print("Test score:")
print(lm.score(x_test, y_test))

plt.scatter(y_test, y_predict)
plt.plot(range(20000), range(20000))

plt.xlabel("Prices: $Y_i$")
plt.ylabel("Predicted prices: $\hat{Y}_i$")
plt.title("Actual Rent vs Predicted Rent")
